I want a website for workshops wit microbit projects

The site will be a collection of workshops.

Worksshops can be free or private.
When private, you need a code to open the workshop

A workshop is a collection of projects with metadata.
A workshop has start and end date/time.
Projects within a workshop has an order.
Some projects are only avillable when an other project is finished

A project is a collection of documents and images needed to forfill a task.
Projects can be assigned to (multiple) workshops.
Projects have a target and a status (not started yet, in progress, finished)

A manager can create projects and workshops.

The site is hosted in Vercel hobby (with git repo) and made with the latest angular version.
